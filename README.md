This project is a Python-based PDF to Audiobook Converter that reads text from a PDF file and converts it into spoken audio using Google Text-to-Speech (gTTS). The program extracts text from all PDF pages and saves the audiobook as an MP3 file.

Features:
Reads text from PDF documents
Converts PDF text into speech
Generates MP3 audiobook files
Supports different speech accents and playback options
Automatically plays the generated audiobook

Language:
Python

Libraries Used:
gtts
PyPDF2
os
